# Experiment 2 – AI-Powered Blog Content Generator

## Aim
To generate blog content using a topic and writing style supplied by the user.

---

## Sample Question
An educational website needs a simple blog generator. Develop a Python program that accepts a blog topic and writing style, generates a suitable title and blog content using Ollama, displays the result, and saves it in a text file.

---

## Sample Dataset
No external dataset is required. The user provides the input while running the program.

---

## How to Run
```bash
python blog_generator.py
```

---

## Sample Input / Expected Output
- **Topic:** `Benefits of Artificial Intelligence`
- **Style:** `Informative`
- **Output:** The model generates a title, introduction, main content and conclusion, and saves the result in `blog.txt`.

---

## Files in This Folder
- `blog_generator.py` – Python experiment program
- `ollama_helper.py` – Ollama helper module
